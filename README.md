# Kodigo Web Studio

> *"Websites that work as hard as you do."*

**Kodigo Web Studio** (*Kodigo* — Filipino for "code") is a responsive business proposal and web agency showcase designed to help local small businesses transition from social-media-only selling to fast, reliable, custom-built websites.

---

## Key Features

- **Complete 8-Section Business Proposal:** Structured across **Home**, **About**, **Products & Services**, **Target Market**, **Marketing Strategy**, **Operations**, **Financial Proposal**, and **Contact**.
- **Interactive Startup Cost Calculator:** Dynamically sums equipment, software, and registration expenses in real time using vanilla JavaScript.
- **Projected Income & ROI Calculator:** Calculates estimated monthly revenue based on service tiers and automatically determines how many months it takes to recover initial startup capital.
- **Dynamic UI & Validation:** Includes a hero typing effect, responsive service cards, an operations accordion workflow, and client-side contact form validation.
- **Human-Centered Layout:** Balances structured pricing cards with varied section layouts, realistic pricing rationale, and founder storytelling.

---

## Tech Stack & Structure

- **Markup & Styling:** Semantic HTML5, CSS3 (Custom Flexbox & CSS Grid), Bootstrap 5 (Responsive Grid, Navbar, Cards, Accordion, Tables)
- **Interactivity:** Vanilla JavaScript (DOM manipulation via `getElementById`, event listeners, form validation)
