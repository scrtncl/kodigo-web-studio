Inside the project

The problem

A slow or broken connection can have several causes. Separate readings are difficult to interpret without a clear sequence of checks and a useful next step.

What I built

The source separates the browser interface from the Python diagnostics. A local server connects the pages to checks, saved reports, device information, and monitoring history.

Beyond the dashboard

The project also includes device management, connection history, speed testing, and a technician interface that draws on saved diagnostic data.

From a question to a finding

  1. 01
    Choose the check

    Full connection, local network, or DNS diagnosis.

  2. 02
    Collect the evidence

    Check local configuration, gateway reachability, DNS, and internet access according to the selected scope.

  3. 03
    Read the next step

    Review measured facts, a probable cause, what remains unverified, and a recommended action.
